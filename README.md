# Weather Prediction using Machine Learning

Predicts whether it will rain tomorrow in Australia using logistic regression
on the Rain in Australia dataset (`weatherAUS.csv`).

## Steps
1. Data cleaning and imputation
2. Scaling numeric features and one-hot encoding categories
3. Logistic regression, with training/validation/test accuracy
4. Baseline comparison against random guessing and always predicting "No rain"

## Tech
Python, pandas, scikit-learn, seaborn, Matplotlib
